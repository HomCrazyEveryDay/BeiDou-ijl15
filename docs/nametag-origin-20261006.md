## 原因与实现

目标客户端 PE 时间戳 `4B7C15C9`，映像大小 `A94000`，基址 `00400000`。
原生函数 `005F0334` 绘制左右及中间三块名牌：

- `[ebp+20h]` 保存三块图片最大的 origin Y。
- 中间 `005F0BF8` 和左侧 `005F0CAC` 已按 `maxOriginY - originY` 绘制。
- 右侧 `005F0D2E` 固定压入 Y=0，经 `005F0D36` 调用 `IWzCanvas::Copy`，导致上述两款右侧分别偏上 3、4 像素。

`NameTagOriginFix.h` 在右侧 Copy 调用点安装桥接，以原生 `0040F0C2` getter 读取右侧原点，修正唯一的 Y 参数后尾调用原始 Copy。保留来源图片、画布尺寸、中心重复填充、X 坐标、文本、透明度和 HRESULT。原点相同的旧款继续使用 Y=0；共享此原生分支的名牌遵循同一原点规则。

安装前核对 PE、周边指令、原始调用及 getter 签名。保护页操作失败时回滚，不对未知 EXE 安装。仅在启动记录一次 `nametag.origin install result=1/0`，无逐帧日志。
