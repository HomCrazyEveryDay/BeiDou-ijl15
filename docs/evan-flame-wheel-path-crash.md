实际记录：客户端 PID 2572，09:25:21Z 附近，资源读取 /1，HRESULT 80030002，C++ E06D7363。来源记录 2709..2717 的调用位置均为 0095611B，入队参数 raw7=0；路径在入队时即是 /1。调用栈经过 00969B3D、0094FA2D。这是原生连锁弹道生成调用，不是商店或技能册处理。

修复：00955E21 比较的立即数由 22181001 改为 22171003，保留原条件跳转到 00956372；00955EDD/00955F1E/00955FB1 只比较 22181001。083 00955C48 调用弹道路径读取函数 009556AB，该函数优先读技能等级记录+1A8，后备技能记录+80；资源加载器 0075DACB..0075DBA4 仅在 ball 存在时初始化+80。火焰轮无 ball，因此错误进入弹道分支会传入空路径，随后随机编号拼出 /1。
