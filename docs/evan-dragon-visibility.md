# 骑乘跟随龙显示修复

084 的 507E1F..507F76 读取 owner+544 的骑乘模型，对龙图层 alpha 执行 (0,0)/(255,255)。083 的更新流程缺少对应骑乘分支。

旧钩子使用 VARIANT 指针调用 COM RelMove，实际原生调用按值复制两个 16 字节 VARIANT；调用栈布局错误。20260923-145131187Z 的崩溃点 4FF7A4，ECX=80020004（DISP_E_PARAMNOTFOUND），与该错误吻合。报告中的最近资源请求不是资源错误的证据。

新补丁在 4FF025 的原生更新调用后，保存寄存器和标志，使用 EBX 中的 CDragon 更新透明度。COM E4 获取 alpha、90 调用 RelMove、08 释放引用；两个 VARIANT 均按值传递。纳入 EvanRuntime 签名检查后安装，对本人和远端跟随龙走同一流程。未删除服务端跟随龙对象。

隔离测试通过实际补丁入口执行：非骑乘、三个阶段、下骑恢复，检查 COM 参数、透明度及引用释放。游戏原生更新与 COM 对象由测试替身代替，因此不等同于实机显示验证。Release/x86 构建后同步客户端并校验 SHA-256。

事件日志 evan_dragon_visibility 仅在模型变化时记录，每进程最多 96 条，可通过 BEIDOU_EVAN_MOUNT_LOG=0 关闭。用户验证登录、上骑、下骑、骑乘中切图以及其他角色视角；实机结果待反馈。
