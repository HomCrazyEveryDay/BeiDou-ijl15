# 魔翼痛击（22151002）GMS 084 → 083

## 原版依据

来源是本工作区 `BeiDou-v84/reference/084/MapleStory` 的 GMS v84.1 WZ，以及同目录上一级的 `GMS_v84.1_L.exe`。客户端技能、龙动作、声音已与来源逐项核对；没有改动技能贴图、音效、数值或套用其他技能动作。

- `Skill/2215.img` 的 706 项结构、数值、像素签名一致；文件均为 170273 字节。
- `Character/Dragon/2215.img` 的 927 项签名一致；2216～2218 的 killingWing 动作也一致。
- 满级为魔法基础攻击力 320、MP 35、单目标一段、暗属性；320 不是伤害百分比。原版没有此技能的 DOT 或冷却字段。
- 原版 `Character/00002000.img/killingWing` 有 10 个动作阶段，083 客户端缺少该节点及其动作注册。

## 修复

服务端 `AbstractDealDamageHandler` 在命中时为该技能设置 HOMING_BEACON 目标 OID；`StatEffect` 使用已有原生状态和封包，换目标更新 OID，换图复用既有状态清理。083 的 `0076662D` 与 084 的 `00788A6D` 都将 5211006、5220011、22151002 分类为该原生状态，不额外增加持续伤害或伤害加成。

服务端 `wz/Character.wz/00002000.img.xml` 和客户端 `Data/Character/00002000.img` 增量补入原版 killingWing。orange-wz-cli 验证 49/49 项；MapleLib 独立比较只增加该节点的 49 项、删除 0 项，文件从 140833 增至 141421 字节，保留已有 ghostLettering 等修改。

`EvanKillingWing.h` 在保留原有动作编号的前提下追加人物动作 162 和龙动作 21：

- 重定位人物、龙动作表的原生引用；`EvanActionTableRefs.inc` 记录每处操作数及预期原始地址，安装前完整校验。
- 原生初始化末尾构造 killingWing 名称，同时扩展查询终点、动态数组长度、动作上限和析构数量。
- 人物结构里的两套固定布局缓存不能直接加长；新增动作的普通/骑乘缓存单独存储，通过 `00454564`、`0045279C` 接入读取，通过 `00453A38`、`00450093` 接入重置/析构，调用原生数组析构器释放。其他动作走原指令。
- 依据 084 `0099247B`，在 083 `00955E26` 为魔翼痛击补齐 WZ lt/rb 矩形选怪分支；保留已有火焰轮分支。
