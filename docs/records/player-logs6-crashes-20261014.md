## 第一处：创建 Vector2D 时类名长度为零

运行 `20261014-140558801Z-pid13536`，`clientRunId=cd0c2270d2b088778de3a55044a43e14`，连接后缀 `-30302`，线程 11420。异常对象 `0019E798` 内保存的 HRESULT 为 `800401F8`。

现场首轮异常记录包含同一时刻的 `PCOM+5075 ← PCOM+4E67`，随后原生工厂包装器重新抛出 `_com_error`。实际栈包括：

```text
00447FA2 ← 0043FF62 ← 0044514B ← 00A03425
← DeathDialogDiagnostics::UpdateHook ← 00531BAF
```

`0043FF3B` 从 StringPool 索引 `3BE` 获取类名，`00406292` 构造传入字符串，`0043FF5D` 调用 `00447F40` 的工厂包装。静态索引内容是 `Shape2D#Vector2D`，不是应当为空的配置项。

PCOM 的 `+5021` 函数在 `+502E..+5048` 检查字符串持有者/BSTR，读取 `[BSTR-4]` 的字节长度并除以二；`+5054..+5070` 在结果为零时构造 `800401F8` 并抛出，返回地址正好为 `+5075`。这是在查找模块之前失败的分支，与早期样本中 `PCOM+52CF` 的模块句柄分支不同。不能仅凭相同 HRESULT 判为缺少 Shape2D.dll、PCOM 模块退出或同一旧故障。

离线实验使用正式 PCOM：

```text
factory key='Shape2D#Vector2D' hr=00000000 object=non-null
factory key='' hr=800401F8 object=null
CXX first chance PCOM offsets: 5075 4E67
```

空类名实验与现场分支一致，但这是失败输入重放，不是自然复现导致空值的过程。mini dump 未保存相关字符串堆内容，不能进一步分辨 null 持有者、null BSTR 或零长度 BSTR，也不能定位首次错误写入者。栈上有 UpdateHook 不证明该 hook 导致了空字符串。

## 第二处：混染头发 info 对象为空

运行 `20261014-140556731Z-pid11204`，`clientRunId=dfbab34209632e8eaf851787d57391d9`，连接后缀 `-30321`，线程 7096。异常对象 `0019DE6C` 的 HRESULT 为 `80004003`。

实际链为 `00402648` 的 IWzProperty 空指针保护抛错，返回点 `0040264D`；调用者位于 `GetCharacterImg(0040A2C7)` 内的 `0040A50E`，返回点 `0040A513`。随后是 `0041296D / 0041283C` 的动作加载和 DLL 中的 `EvanRuntime::MountBodyTraceGate / AvatarLayerBuild_Hook`。

`GetCharacterImg` 帧 `0019DF58` 的关键值：

| 位置 | 值 | 含义 |
| --- | --- | --- |
| `EBP+0Ch` | `40008B47` | 正在加载的外观资源 ID |
| `EBP-44h` | `7D54ACB0` | 已取得的根 IWzProperty，非空 |
| `EBP-1Ch` | `00000000` | 根节点下查询出的 info IWzProperty，空 |
| `EBP-14h` | `83215B80` | 原生角色资源缓存条目 |
| `EBP-4` | `0D` | 与 info 查询/清理后的 SEH 阶段一致 |

指令顺序是：取得根资源 → 用 StringPool `3C1`（`info`）调用 `get_item` → 转为 IWzProperty → 清理原 VARIANT → 用 StringPool `474`（`islot`）准备下一次查询 → 解引用空 info 时抛错。并不是已经读到一个错误的 islot 文本，也不是脸饰 Canvas 的失败点。

`0x40008B47 = 1073777479` 按当前协议解码为**主色头发 35655、副色头发 35650**；标记和重编码均合法，不能把该大整数当成随机损坏 ID。这可能是同屏角色的外观，现有栈不能认定为该账号自身的头发，更不能认定玩家必须打开混染窗口才会触发。

`MountBodyTraceGate` 位于通用动作链上；相关修改仅对指定龙神坐骑/姿势生效，其他输入走原函数。仅凭符号出现在栈上不足以归因为龙神、坐骑或死亡弹窗。原查询 VARIANT 已被清理，缺少根属性的堆内存，尚不能确认 info 为何为空：可能是查询键/返回对象/运行期状态异常，也不能排除玩家磁盘资源与本地不同。
