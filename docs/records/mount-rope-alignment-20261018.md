## 修正范围

`MountRopeAlignment.h` 只替换上述六个 CALL。每次读取对应控制器所属角色的当前骑乘状态及**已经按朝向翻转**的身体 X 偏移，先将搜索线段两个端点的 X 一同平移交回原版函数；未命中时，再用原始物理坐标查询，保留原本能抓到的绳梯。两次均命中时，以身体显示位置对应的绳梯为准。零偏移或平移溢出时只查原始坐标。

适用于 190/193 骑乘类别，无机车 ID 白名单或固定 20/25 像素补丁；后续资源仍通过原生渲染算出的偏移适配。使用实际 owner，避免私有预览错误借用野外角色状态。没有骑乘、身体原点未准备好、owner/controller 不匹配时走原坐标。

每次查询保持原版 ±10 横向容差，不将两条查询线段合并为大矩形；相对于旧版单一平移查询，当前允许命中的位置是显示位置与原生物理位置两套范围的并集。不移动人物、机车、地图绳索或物理坐标。Y 及原生地面/顶部进入条件保持原逻辑：骑乘座位的垂直高度本身不能证明应该提高抓绳高度。本修正也不处理未证实的纵向问题或已经上绳后的画面问题。

安装前核对原生查找函数、显示偏移计算/存储指令及六个 CALL 的目标。预检不符不写入；写入失败尝试回滚。仅记录一条生命周期日志 `event=mount_rope_alignment install=ok/failed`，没有逐帧日志或扫描。
