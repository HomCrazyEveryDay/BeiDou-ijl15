# 龙蛋孵化过场随游戏分辨率缩放

原背景为 800×600，米尔为 460×485（原点 207,235），蛋壳为 781×233（原点 394,-67）。单独放大背景会使人物、蛋壳和光效仍保持旧尺寸。

客户端使用当前 `Client::m_nGameWidth/m_nGameHeight`：背景填满画面；前景统一按 `min(width/800,height/600)` 缩放像素和有符号原点，保持龙、蛋壳及光效的比例与相互位置。窗口模式适配游戏内容区，全屏适配游戏分辨率，不更改显示器设置。原始 IMG/XML、播放时序和转职条件不变。

本地 BeiDou.exe 静态核对：

- 场景 cue Update 位于 `0043A8C4`，thiscall，唯一参数 tick，结尾 `ret 4`；入口字节 `B8 09 A0 A7 00 E8 CA 62 62 00`。
- cue 的 type 在 +0、宽字符串 visual 在 +4、x/y 在 +10/+14。解析器 `0043A505` 写入 visual；播放器 `0043AC09` 读取原字符串（`0041468C` 是读取首指针的访问器）。
- type=0 在 `0043ADCE` 调用 `004398F6`，继而在 `00439953` 调用 `0043EA3E`，最终使用现有 `00426BAB` InsertCanvas 包装器。不是通用路径图层工厂 `0043E86F`。
- 仅四个 incubation 路径且 x=y=0 的 cue 开启线程局部缩放上下文；返回或 C++ 异常展开恢复此前上下文。原动画 delay/alpha/zoom 参数透传，保留原 callback。
- 复用梦境 InsertCanvas 拦截点，但新增逻辑不改变既有梦境缩放。入口字节不匹配则不装 hook，记录一次安装结果。

验证：`tests/IncubationCanvasTest.ps1` 直接加载本地 PCOM/Canvas 绘图库，不启动游戏，覆盖五种分辨率、裁剪帧、负原点、透明及半透明像素、源画布不变、路径隔离。原 `DreamCanvasTest.ps1` 回归通过。Release|x86 构建通过（现有 detours PDB 缺失警告）。

实机待用户验证：重新启动客户端，触发一次孵化；背景覆盖游戏画面，米尔保持比例，蛋壳与光效相对位置正确，动画结束正常返回并完成一转。离线测试不代表游戏内 hook 和最终视觉已验收。
