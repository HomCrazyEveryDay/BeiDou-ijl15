# 战神解除前置后的手搓指令

移除幻影狼牙、钻石星尘的 WZ `req` 后，斗气爆裂可以洗到 0。
但 083 客户端的手搓注册入口还有独立的硬编码条件：

- `0x0074C505` 开始查询斗气爆裂（21100004）等级。
- `0x0074C510` 调用 `CSkillInfo::GetSkillLevel`（`0x007616F6`）。
- 返回等级大于 0 时才加入指令槽 9、10，对应两个方向的“↓→＋攻击”。
- `0x0074D352` 之后的施放选择则独立检查钻石星尘、幻影狼牙、斗气爆裂的真实等级和 200／100／30 连击门槛。

因此仅有钻石星尘时，选择逻辑正确，但没有指令入口，输入退回普通攻击。

`AranComboCommand` 仅替换 `0x0074C510` 的调用：三种攻击技能任一种已学即可注册这两个指令槽。
不修改全局技能等级查询，不修改后续施放选择、连击消耗、普通攻击或吸血／护盾指令。
三种技能都为 0 时不注册；低阶技能为 0 时不会被后续选择器选中。
安装前校验原始调用字节，失败写入现有生命周期日志。

本次只需 DLL 修复。服务端已有真实技能等级和连击消耗逻辑，前置解除的 XML／IMG 已于上一轮同步，无须再次改数值、资源或描述。

验证：`tests/AranComboCommandTest.ps1` 在独立内存中执行原 EXE 注册与技能选择代码，先复现“0／0／30、200 连击”没有注册指令，再检查修复后的 243 种技能等级／连击组合、两个方向的指令槽、等级和连击不被改写、签名拒绝与重复安装。测试不启动游戏、不连接服务器。最终手搓动作由用户重启客户端后实测。
