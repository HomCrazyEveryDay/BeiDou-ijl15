## 普通发型读取遗漏

前一轮的本色 rope → ladder 引用只在混染合成器中生效。`MixedDye.cpp::ParsePath` 原本仅接收带混染编码的 ID，`!hair`、未染色外观和混染前预览读取普通 ID，直接绕过合成兼容；原 IMG 中缺失的 rope 仍然缺失。这是上一轮覆盖范围遗漏，之前双向混色检查不能证明普通发型已修复。

本轮把已确认的 `40902`、`43206`、`44092` 普通 Hair 路径纳入现有资源 hook。通过原始接口装载资源，再以同一颜色构建只读的运行时属性树，使用既有本色 ladder/backDefault 画布补出 rope。普通资源两侧都没有 rope，必须在根属性枚举时显式加入别名节点；不能只合并两个原始 key 集合。根路径与 `/rope/1` 等子路径都使用同一个受限缓存。

规则依据仍是 CMS228.2 同款另七色的 rope/ladder 引用一致，使用目标颜色自己的完整背面图片。不修改任何 Hair IMG、像素、ID、坐标或图层名。混染 ID 的两色合成保留，其他普通 ID 和 Face 路径直接交回原生读取。缓存仍限制 128 项/32 MiB；原有失败回退和资源类别校验保留。

- `0081DEEE–0081DF1B`：消耗/设置/其他栏直接显示数量，现金栏由 `004863D5` / `00486845` 的旧分类判断决定是否继续。
- `0081DF1D–0081DF21`：通过物品虚表 `+0x20` 读取实际数量。
