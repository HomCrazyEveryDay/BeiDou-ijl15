# 混染窗口关闭后阻挡物品栏鼠标

日期：2026-10-03。范围：本地 083 客户端混染 DLL；未改物品、WZ、服务器扣券或生产环境。

## 现象与依据

用户确认双击混染券打开窗口，再关闭后，鼠标仍无法正常指向物品栏中的券。

旧 `Close` 只隐藏三个图层、释放预览和键盘焦点，没有执行原生窗口注销。083 `CWndMan` 在 `0x009E42B2` 按窗口列表查找鼠标目标，调用主虚表第 9 项 `HitTest`；当前沿用的 `0x00424461` 调用 `0x009E01E7`，在无子控件时只检查 `CWnd +0x24/+0x28` 的宽高，不检查隐藏状态。设置 `IsShown=0` 不会让这个无子控件的窗口矩形自动退出命中，因此其后面的物品栏收不到鼠标。

原生 `CWnd::Destroy`（`0x009E00AF`）释放图层并移除窗口列表及输入注册。`CWndMan +0x88` 是键盘焦点、`+0x8c` 是当前鼠标目标、`+0x90` 是拖动捕获拥有者；`0x009E3AC0` 用于结束捕获。修复只处理属于混染窗口的焦点和捕获，保留其他 UI 的所有权。

## 修复

- 真正关闭时先标记隐藏、结束会话，释放焦点／捕获／角色预览，再调用原生 Destroy 注销；保留 CWnd 对象，下次打开通过原生 CreateWnd 重新注册。
- 主虚表第 9 项增加隐藏、未就绪、无会话时返回不命中的保护。有效窗口仍调用原生 HitTest，保留原始尺寸和边界。
- 已隐藏窗口的鼠标回调不再更新选择或重新获得焦点；临时隐藏仍可按原有 Show 流程恢复。
- 取消消息发送失败也继续本地清理；重复关闭不会重复 Destroy。
- 新增原生 Destroy、HitTest 和捕获结束入口的字节签名检查，避免在不支持的 EXE 上调用错误地址。
