# 龙推力与火焰轮动作注册补齐

技能 22141001 使用 `dragonThrust`，22171003 使用 `flameWheel`。客户端已有 Skill/Dragon/2214～2218.img 的龙推力画布，以及 2217～2218.img 的火焰轮画布，但人物基础 Character/00002000.img 缺少两种动作，083 的人物和龙动作表也未注册这两个名称。伤害分支能执行不代表特效动作能加载。

在既有 StringPool hook 中，将当前技能不再引用的原型名称 dragonSpark（5491）和 dragonFly（5503）分别注册为 dragonThrust 和 flameWheel。两处名称各被人物、龙动作表共同读取：5491 的原生调用点为 004A5B71 / 004A9B29，5503 为 004A5F22 / 004A9C73。原始机器码已核对；这两个表项地址的引用只出现在注册代码中。保留原技能 ID、action 名称和原版图片，不借用其他技能动画。

人物动作来自已提取并完成像素反读验证的 GMS084 Character/00002000.img，SHA-256 为 A175EE36D44972777A71C51F61D047F63B9EFF976B3CA81263D65AECA565E5E1。使用 BeiDouWzTool evan-merge 增量加入龙推力 10 帧、火焰轮 11 帧，保留原始 delay、move 和基础动作引用。同步服务端现有 Character XML；没有技能数值或服务端伤害逻辑改动。IMG 从 138279 增至 139501 字节，往返结构及无关像素校验通过。

验证：原生注册调用点、原型名称未被现有技能使用、084 原版动作逐节点一致、人物帧引用和对应成长阶段龙动画依赖通过；EvanBlazeDispatchTest 通过，涵盖火焰轮与熊熊烈火分派及魔龙分身时序回归。DLL 使用 Release|x86 构建并同步客户端，安装后核对 SHA-256。游戏实机尚待用户确认：左右朝向、连续施放、命中多怪、转地图后施放，以及熊熊烈火、闪电箭等现有技能回归。
