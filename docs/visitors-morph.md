# Visitors Morph 64–67 客户端兼容

`ezorsia/VisitorsMorph.cpp` 为 GMS083 补充 GMS092 外星访客攻击兼容。只处理 Morph 64、65、66、67 和当前职业匹配的 1066/1067 技能族，不修改角色已学技能表、键位表、资源、封包格式或服务器状态。

## 基线与范围

- 083 EXE：ImageBase `00400000`，PE timestamp `4B7C15C9`，SizeOfImage `00A94000`；静态核对样本 SHA-256 `6c4fc608e5b44708d19f07d5b88729126539e919d0b79035da76610158f355c2`。
- 092 参考样本 SHA-256 `1bd2ac478977bf56e3a9f9cb3f01f9d253e1a7683f8973ce6b975aaf38c1475b`；输入、等级、动作和伤害语义以该样本反汇编为依据。
- 普通攻击替换成 1066，已有非空 type=1 技能键替换成 1067。替换点位于原输入状态检查之后，继续进入 `00966F7A`，保留场景禁技能、死亡、施放中、骑乘、冷却、资源消耗等原流程。
- 前缀镜像 092 `00479E90`：2001/22xx 为 `20010000 + base`；其余支持职业为 `(job / 1000) * 10000000 + base`；不引入 3000 系职业。
- 普通技能等级查询合成 1；仅施放取等级的调用点返回 `morph - 63`。普通查询还核对 `CWvsContext+20B8` 的 CharacterData 身份，避免给其他角色或预览角色合成技能。
- 新模块在现有 Hook 注册流程中安装，不重复 detour 原有龙神、战神补丁点。`00761717/00761723` 的龙神等级补丁和 `00980760` 的远端动作诊断均保留。

## 数值、范围与原生报文

`00950921` 使用施放等级读取完整等级数据。原路径已支持 `attackCount`（安全整数 `+100/+108`）、`mobCount`（`+130/+138`）以及 `lt/rb`（矩形 `+16C`）；继续使用原生矩形朝向翻转、坐标偏移、目标选择、段数限制和 CLOSE_RANGE_ATTACK 编码，不新增字段。

固定伤害补丁对应 092 `00714482/007144A4 → 00714582` 的特例：绕过普通 fixdamage 的局部命中率计算，写原客户端伤害槽。之前的通用免疫/状态分支仍然保留，不宣称对任何无敌怪都能命中。

2026-10-22 只读核对已安装的服务端源文件 `BeiDou-Server/gms-server/wz/Skill.wz/000.img.xml`；以下为实测对照值，不在 DLL 中硬编码：

## Reactor 闭环依据

不新增 Reactor patch，避免重复发包或绕过 activeSkillID：

1. 施放成功后原流程 `009693CD/009693DD` 将 ESI 中的完整 skillId 传给 `00735AB7`。
2. 原 loader `0073A4B5` 读取 `activeSkillID`；`00735BCA/00735BCD` 将完整技能 ID 与列表逐项比较，不截断职业前缀；继续检查角色是否位于当前事件矩形内、反应堆忙状态和延迟。
3. 原 `00735C6B` 构造 opcode `00CD`；`00735CAA → 00735CB0` 将原 skill 参数 Encode4 写入 HIT_REACTOR 的 offset 16，总长 20 字节，然后原 `00735CBF` 发送。
4. 只读核对 `wz/Reactor.wz/5022000.img.xml`、`5022001.img.xml` 的事件列表包含四种 083 职业前缀的 1066，不包含 1067。资源保留的 30001066 条目不意味着 DLL 支持该职业。

离线测试执行了原比较和编码指令块，编码器替换为内存收集器，停在发送之前；证明完整 ID 的静态/离线流向，不等同实际游戏网络抓包或反应堆已击碎。

## 验证与交付

- 运行 `tests/VisitorsMorphTest.ps1`：将 EXE 节只读加载到隔离测试地址，不启动游戏；逐点测试签名损坏拒装、无部分写入、幂等安装、龙神补丁共存、x86 栈/寄存器、所有职业前缀、四档等级、输入替换、动作、固定伤害、非 Visitors 回退和 `00764256` 原查询路径。
- 构建入口按根 AGENTS.md：完整路径 MSBuild，`ezorsia.sln /p:Configuration=Release /p:Platform=x86`。构建后先 `tasklist /FI "IMAGENAME eq BeiDou.exe"`；无客户端进程时同步 DLL 并比较 SHA-256。
- 安装诊断：Lifecycle 的 `event=visitors_morph_install version=1 success=1 patches=9`；签名失败会有 `reason=signature`。技能资源查不到时仅记录一次 `event=visitors_morph_missing_resource`，不合成有效等级。

### 用户实机验收

1. 使用配套服务端实现进入 `502010200`，在深海取得 Morph；不要手工学习或绑定隐藏的 1066/1067。
2. 普通攻击检查 stabO1；按一个已绑定的非空技能键检查 stabO2。空键、道具键、功能键不应替换。分别向左/向右、空手/不同武器测试。
3. 按上表验证四种 Morph 的跳字、段数、目标数；检查远程技能的攻击范围、无目标挥击和连续输入。
4. 靠近飞船残骸 `5022000/5022001` 的有效事件矩形，普通攻击应逐状态击碎；技能键的 1067 不应通过其 activeSkillID 条件。网络验收核对 HIT_REACTOR 最后 DWORD 为相应前缀 1066，不是 0 或 1067。
5. 变身解除/到期后，原攻击、原技能和其他变身应恢复原行为；死亡、场景禁止、施放中、冷却时不得借此绕过限制。
6. 使用另一角色观察本地/远端动画和伤害广播；覆盖四种 Morph、四类职业、跳跃/游泳/攀爬姿态。

尚未实机验证：动画帧、全部姿态/武器、服务器数值校验与扣血、远端广播、地图中 Reactor 实际触发。离线测试和构建通过不代表这些项目已验收。
