# 角色卡提示与成功回执

2026-09-24：GMS083 `BeiDou.exe` 的 StringPool 5043 是 B 型角色卡购买时的空栏位提示，5048 是创建成功提示。两者属于客户端内置文字，不属于 WZ；在现有 StringPool hook 中按 ID 和原文核对后返回 GBK 中文，仅中文模式启用。

客户端 `007D7586` 将封包 `0x15E` 分派至 `007D77B0`。后者依次读取 byte 类型和 int 状态：`007D77F4` 比较类型 `0x34`，`007D77FD` 比较状态 0，成功时 `007D780C` 读取 StringPool 5048，并更新客户端角色数量。类型 0 会落入未知错误格式化分支，即使状态为 0 也不会成功。

服务端配套新增 `PacketCreator.sendMapleLifeSuccess()`，发送 `0x15E / byte 0x34 / int 0`。角色卡创建成功分支调用它，移除重复的 showHint；真正失败的原有回执保持不变。协议回归测试检查完整字节布局。

实测：购买 B 型角色卡时检查中文提示；使用角色卡完成创建，检查仅弹中文成功提示、卡片扣除且角色列表只增加一个角色。客户端交互由用户执行。
