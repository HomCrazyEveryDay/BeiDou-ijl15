# 客户端连接地址白名单

默认入口仍为 DLL 内的 `114.132.97.50:8484`。可在本机 `config.ini`
的 `[dev]` 节启用地址覆盖；`[general]` 的地址字段不参与连接配置。

```ini
[dev]
enableLocalEndpointOverride=true
ServerIP_Address=103.14.77.46
serverIP_Port=18484
```

允许 localhost、IPv4 回环、10/8、172.16/12、192.168/16，以及以下明确白名单：

- `103.14.77.46`
- `114.132.97.50`
- `13.212.38.93`
- `69.165.65.146`（2026-09-15 本机 `ssh -G hk146` 的 HostName）

白名单按完整 IPv4 地址匹配，其他公网地址不允许覆盖。端口范围为 1–65535。
无效地址或端口保留默认入口。此开关名称为历史兼容而保留。

示例端口不代表已验证中转后端。登录端口及服务器下发的频道地址都必须可达，
白名单不会更改远端防火墙或中转规则。SSH 别名不会在客户端运行时解析；
别名指向改变时需重新核实白名单。
